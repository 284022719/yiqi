# DPS职业层级排名功能

## 功能概述

本功能基于 [Wowhead](https://www.wowhead.com/cn/guide/classes/tier-lists/dps-rankings-raids) 的DPS排名数据，在公会网站中展示魔兽世界各职业专精的层级排名。

## 数据来源

- **来源网站**: Wowhead
- **作者**: Dratnos
- **更新时间**: 2025/08/09
- **版本**: The War Within Season 3
- **副本**: Manaforge Omega Raid

## 文件结构

```
js/
├── data/
│   └── dps-tier-list.js          # DPS排名数据
├── modules/
│   └── DPSTierList.js           # DPS Tier List显示模块
└── main.js                      # 主文件（已更新）

pages/
└── dps-tier-list.html           # 专门的DPS排名页面

index.html                       # 主页面（已添加DPS排名容器）
```

## 使用方法

### 在主页面显示
DPS排名已集成到主页面中，会自动显示在成就点数排行榜之前。

### 访问专门页面
可以通过导航菜单的"DPS排名"链接访问专门的DPS排名页面：
```
/pages/dps-tier-list.html
```

### 测试页面
可以使用测试页面验证功能：
```
/test-dps-tier.html
```

## 更新说明

当Wowhead发布新的DPS排名时，只需要更新 `js/data/dps-tier-list.js` 文件中的数据即可。

## 层级颜色标准

根据参考图片，各层级的标准颜色为：
- **S Tier**: #FFD700 (金色)
- **A Tier**: #FF6B6B (红色)  
- **B Tier**: #4ECDC4 (青色)
- **C Tier**: #A8E6CF (浅绿色)
- **D Tier**: #FFB6C1 (浅粉色)
- **F Tier**: #D3D3D3 (浅灰色)

## 卡片设计

每个专精卡片具有以下特点：
- **统一宽度**: 200px (桌面端) / 180px (平板) / 160px (手机)
- **职业底色**: 使用对应职业颜色的20%透明度作为背景
- **左侧边框**: 使用对应职业颜色的实线边框
- **悬停效果**: 鼠标悬停时显示金色边框和阴影效果

## 注意事项

1. 排名基于团队副本表现，与大秘境表现可能不同
2. 排名会随游戏版本更新而变化
3. 个人技术水平和装备对实际表现影响很大
4. 建议选择喜欢的职业专精，享受游戏乐趣
