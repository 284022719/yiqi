## API解析结果

### 🎯 核心发现

#### 1. API端点结构
```
基础URL: https://webapi.blizzard.cn/wow-armory-server/api/do
参数: api=mythic_keystone_season&token={token}
```

#### 2. 数据层次结构
```
响应数据
├── best_runs (最佳记录数组)
│   ├── dungeon (地下城信息)
│   ├── keystone_affixes (词缀信息)
│   ├── members (团队成员)
│   └── mythic_rating (评分信息)
├── character (角色信息)
├── mythic_rating (总体评分)
└── season (赛季信息)
```

#### 3. 关键数据字段
- **completed_timestamp**: 完成时间戳
- **duration**: 完成时间(毫秒)
- **keystone_level**: 钥石等级
- **is_completed_within_time**: 是否限时完成
- **mythic_rating.rating**: 评分数值
