## 技术特性

### API功能覆盖
- **角色信息**: 基本信息、装备、专精、等级等
- **副本数据**: 团队副本进度、大秘境信息
- **PVP数据**: PVP摘要和详细信息
- **收集品**: 坐骑、宠物、猎人宠物
- **成就系统**: 成就分类、进度、详情
- **公会信息**: 公会成员批量获取
- **外部数据**: 副本和成就JSON数据

### 数据规模
- **副本数据**: 182,503 字符 (1,083个项目)
- **成就数据**: 3,003,966 字符 (15个分类)
- **可用模块**: 21个数据模块
- **支持格式**: JSON, CSV

### 编程语言支持
- Python (主要实现)
- JavaScript
- cURL
- PowerShell
